# **Gestor de Hábitos com Chatbot**

Projeto desenvolvido em grupo com o objetivo de criar um site que auxilia usuários a gerenciar e acompanhar seus hábitos diários. 
O sistema permite cadastrar, visualizar e remover hábitos, além de contar com um chatbot integrado para oferecer ajuda, motivação e orientações sobre organização pessoal.

---

## 📌 Funcionalidades
- Cadastro de novos hábitos 
- Visualização da lista de hábitos 
- Remoção de hábitos 
- Login e criação de conta 
- Chatbot integrado para suporte ao usuário 

---

## 🛠 Tecnologias utilizadas
- **HTML5**
- **CSS3**
- **JavaScript**
